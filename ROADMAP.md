# Roadmap

## Now

Useful structured APIs, explicit validation, types, ESM/CommonJS, installed-archive checks, coverage gates, cross-platform CI and honest release-candidate documentation.

## Next

Collect user feedback and real integrations. Prioritize evidence-based improvements over more flags.

## Later

Optional adapters to other DeployAnyway tools through public APIs or pipes. Keep runtime dependencies and telemetry out unless justified separately.
