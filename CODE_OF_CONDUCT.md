# Community conduct

Be kind, specific and curious. Welcome beginners, respect different backgrounds, and critique code without attacking people. Harassment, discrimination, threats and publishing private information are not welcome. Keep humor workplace-safe.

Maintainers may remove harmful contributions and restrict repeated misconduct. Report conduct concerns privately through a maintainer's GitHub profile contact method; do not post sensitive details in public issues. Maintainers should explain decisions respectfully and handle reports confidentially where possible.
